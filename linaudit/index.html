Descripción

Description

linaudit es un chequeo de salud de seguridad para servidores y computadoras Linux. Corre más de cien controles sobre cuentas, SSH, permisos, credenciales expuestas, red, actualizaciones, persistencia y aplicaciones de servidor, y resume todo en un número de 1 a 10 fácil de comparar entre máquinas. Cada hallazgo viene con el comando o la configuración exacta que lo arregla.

linaudit is a security health check for Linux servers and computers. It runs more than a hundred checks over accounts, SSH, permissions, exposed credentials, network, updates, persistence and server applications, and sums everything up in a single number from 1 to 10 that is easy to compare between machines. Every finding comes with the exact command or setting that fixes it.

solo lectura
read-only

Nunca modifica nada del sistema. Cuando encuentra una contraseña o una clave, te dice dónde está, nunca su valor.

It never changes anything on the system. When it finds a password or a key, it tells you where it is, never its value.

puntaje honesto
honest score

Ponderado por gravedad y con techos: con un hallazgo crítico abierto, no hay forma de sacar más de 6.

Weighted by severity and capped: with one open critical finding there is no way to score above 6.

interfaz de terminal
terminal UI

Resumen, hallazgos filtrables y categorías. Buscás, filtrás y copiás el arreglo con y.

Summary, filterable findings and categories. Search, filter, and copy the fix with y.

texto y JSON
text and JSON

Reporte plano para leer o mandar por mail, y JSON para scripts, cron, CI o un colector central.

Plain report to read or email, and JSON for scripts, cron, CI or a central collector.

perfiles
profiles

Servidor, escritorio o contenedor: el criterio se adapta a lo que es la máquina, y lo deja escrito.

Server, desktop or container: the criteria adapt to what the machine is, and the report says so.

Spanish and English

gettext translations embedded in the binary. Adding a language is one .po file and a few lines of code.

Desde el código fuente

From source

You need Rust 1.85 or newer (the version in Debian 13). It works on any distribution and has no runtime dependencies.

Primer uso

First run

$ sudo linaudit
Correlo con sudo. Sin root muchos controles no pueden leer lo que necesitan (la base de contraseñas, las reglas del firewall). linaudit igual corre, pero avisa qué no pudo evaluar y el puntaje no puede pasar de 6: lo que no se pudo mirar nunca cuenta como bien.
Run it with sudo. Without root many checks cannot read what they need (the password database, the firewall rules). linaudit still runs, but it tells you what it could not evaluate and the score cannot go above 6: whatever could not be looked at never counts as fine.

Options

Text report instead of the interactive interface. With --all it also lists the checks that passed.

Exit code 1 if the score is lower than N. Handy in cron, CI and monitoring.

Extra waivers file, besides /etc/linaudit/waivers.conf.

Language for this run. Also LINAUDIT_LANG.

Perfiles

Profiles

No todos los controles tienen sentido en todas las máquinas: un banner legal importa en un servidor corporativo, no en tu notebook; el firewall de un contenedor lo maneja su host. linaudit detecta el perfil que corresponde y te lo sugiere.

Not every check makes sense on every machine: a legal banner matters on a corporate server, not on your laptop; a container's firewall is handled by its host. linaudit detects the right profile and suggests it.

PerfilProfile ParaFor Qué cambiaWhat changes
server servidores, VPS, todo lo expuestoservers, VPS, anything exposed nada: todos los controles con su gravedad completanothing: every check at full severity
desktop computadoras personalespersonal computers relaja los controles de servidor corporativo; el firewall baja de ALTO a MEDIOrelaxes corporate-server checks; the firewall goes from HIGH to MEDIUM
container contenedores y VMs efímerascontainers and ephemeral VMs lo que maneja el host (reloj, firewall, kernel, logs) queda como "no aplica"what the host handles (clock, firewall, kernel, logs) becomes "not applicable"

Un perfil nunca esconde un control: solo le cambia la gravedad o lo marca como "no aplica", y lo deja escrito en el reporte.

A profile never hides a check: it only changes its severity or marks it "not applicable", and says so in the report.

Cómo se calcula el puntaje

How the score works

Cada control pesa según su gravedad. Los aprobados suman su peso, las advertencias la mitad y las fallas nada; el porcentaje resultante se lleva a una escala de 1 a 10.

Each check weighs according to its severity. Passed checks add their weight, warnings half of it, and failures nothing; the resulting percentage is mapped onto a 1 to 10 scale.

CRÍTICOCRITICAL10
ALTOHIGH6
MEDIOMEDIUM3
BAJOLOW1
INFO0

Después se aplican techos, porque un "9 de 10" con un agujero crítico abierto sería mentira:

Then caps are applied, because a "9 out of 10" with an open critical hole would be a lie:

Si queda abiertoIf still open MáximoMaximum
1 crítico1 critical6
2 críticos2 critical4
3 o más críticos3+ critical3
5 o más altos5+ high6
1 a 4 altos1–4 high8
menos del 90 % evaluadounder 90 % evaluated6

El reporte siempre dice qué techo bajó el puntaje y por qué, así sabés qué arreglar primero.

The report always says which cap lowered the score and why, so you know what to fix first.

Excepciones y auditorías periódicas

Waivers and scheduled audits

Aceptar un hallazgo a propósito

Accepting a finding on purpose

A veces un hallazgo es una decisión tomada: por ejemplo, la máquina está detrás de un firewall dedicado. Anotalo en /etc/linaudit/waivers.conf, una línea por control, con el motivo:

Sometimes a finding is a deliberate decision: for example, the machine sits behind a dedicated firewall. Write it down in /etc/linaudit/waivers.conf, one line per check, with the reason:

NET-001   # Firewall perimetral dedicado. Ticket INF-1234Dedicated perimeter firewall. Ticket INF-1234

El control deja de afectar el puntaje, pero sigue apareciendo en el reporte con su motivo: la decisión queda a la vista.

The check stops affecting the score but still shows up in the report with its reason: the decision stays visible.

Una auditoría por semana

A weekly audit

El paquete de Debian trae un timer de systemd (apagado por defecto) que corre la auditoría una vez por semana y guarda el último reporte en /var/lib/linaudit/latest.json, con permisos restringidos.

The Debian package ships a systemd timer (disabled by default) that runs the audit once a week and keeps the latest report in /var/lib/linaudit/latest.json, with restricted permissions.

$ sudo systemctl enable --now linaudit.timer

Traducir linaudit a otro idioma

Translating linaudit

Los textos del código están en inglés y son las claves (msgid) de los catálogos gettext de po/. Los catálogos van embebidos en el binario, así que funciona igual instalado desde el .deb que suelto. Si falta una traducción, se muestra el inglés.

The texts in the code are in English and are the keys (msgid) of the gettext catalogs in po/. The catalogs are embedded in the binary, so it works the same installed from the .deb or as a loose binary. If a translation is missing, the English text is shown.

To add a language (in this example, Portuguese, pt):

  1. Crear el catálogo a partir de la plantilla. Hacen falta las herramientas de gettext (apt install gettext).

    Create the catalog from the template. You need the gettext tools (apt install gettext).

    $ msginit -i po/linaudit.pot -o po/pt.po -l pt --no-translator

    Revisá que el encabezado tenga bien el Plural-Forms del idioma.

    Check that the header has the right Plural-Forms for the language.

  2. Traducir con Poedit, Lokalize o cualquier editor. Los valores van por nombre: {n}, {dir}… y la traducción tiene que conservar exactamente los mismos {nombres}. Los IDs de los controles, las claves del JSON y los valores de la CLI no se traducen.

    Translate with Poedit, Lokalize or any editor. Values are inserted by name: {n}, {dir}… and the translation must keep exactly the same {names}. Check IDs, JSON keys and CLI values are not translated.

    msgid "Found {n} files in {dir}"
msgstr "Encontrados {n} arquivos em {dir}"

  3. Registrar el idioma en crates/linaudit-core/src/i18n.rs: agregalo al enum Lang y a Lang::ALL, completá code(), native_name(), from_code(), catalog() y plural_index(), sumá su constante en set_lang()/lang(), y embebé el catálogo:

    Register the language in crates/linaudit-core/src/i18n.rs: add it to the Lang enum and to Lang::ALL, fill in code(), native_name(), from_code(), catalog() and plural_index(), add its constant to set_lang()/lang(), and embed the catalog:

    static PT: LazyLock<Catalog> =
    LazyLock::new(|| Catalog::parse(include_str!("../../../po/pt.po")));

    El compilador te va a marcar cada match que falte cubrir.

    The compiler will point out every match left to cover.

  4. Verificar y probar.

    Check and try it.

    $ msgfmt --check-format --statistics -o /dev/null po/pt.po
$ cargo test
$ cargo run --release -- --lang pt --fast

    Opcional pero muy bienvenido: una página de manual traducida (doc/linaudit.pt.1) y un README.pt.md.

    Optional but very welcome: a translated man page (doc/linaudit.pt.1) and a README.pt.md.

Mantener las traducciones al día

Keeping translations up to date

Cuando cambian los textos del código, este script regenera po/linaudit.pot y actualiza todos los po/*.po: los textos nuevos quedan sin traducir y los que ya no existen, como obsoletos.

When the texts in the code change, this script regenerates po/linaudit.pot and updates every po/*.po: new texts are left untranslated and removed ones are marked obsolete.

$ contrib/i18n-update.sh

En el código, todo texto visible pasa por tr!("..."); los plurales, por trn!. Un test falla si algún texto del código no está en po/es.po.

In the code, every user-facing text goes through tr!("..."); plurals go through trn!. A test fails if any text in the code is missing from po/es.po.

tr!("{n} files", n = count)
trn!("{n} file", "{n} files", count, n = count)

Colaborar

Contributing

La regla de oro: linaudit es de solo lectura. Ningún control puede modificar el sistema, y ninguna salida puede contener el valor de un secreto (solo el archivo y la línea donde se encontró). Un pull request que rompa esto no se acepta.
The golden rule: linaudit is read-only. No check may modify the system, and no output may contain the value of a secret (only the file and line where it was found). Pull requests that break this will not be merged.

Agregar un control

Adding a check

Los controles viven en crates/linaudit-core/src/checks/, un módulo por categoría. Cada uno tiene un ID estable que no cambia de significado nunca, porque de él dependen las excepciones y los colectores. Sumá el ID nuevo a docs/CHECKS.md y cubrilo con un test usando el fixture de sistema de archivos (checks/fixture.rs), que permite probarlo sin root.

Checks live in crates/linaudit-core/src/checks/, one module per category. Each has a stable ID that never changes meaning, because waivers and collectors depend on it. Add the new ID to docs/CHECKS.md and cover it with a test using the filesystem fixture (checks/fixture.rs), which lets you test it without root.

Advertencias

Caveats

  • Los reportes describen los puntos débiles de la máquina: guardalos en privado.
  • Reports describe the machine's weak spots: keep them private.
  • Algunos controles son heurísticos y pueden dar falsos positivos. Tomá los hallazgos como cosas para revisar, no como veredictos.
  • Some checks are heuristic and can produce false positives. Treat findings as things to review, not verdicts.
  • No reemplaza una auditoría formal de cumplimiento (CIS, STIG), un análisis forense ni un antivirus/EDR. Es un chequeo de salud rápido y honesto que podés correr todas las veces que quieras.
  • It does not replace a formal compliance audit (CIS, STIG), forensic analysis or an antivirus/EDR. It is a quick, honest health check you can run as often as you like.
